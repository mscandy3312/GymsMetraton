# GymsMetraton — ANTYGRAVITY Performance Lab & Consulting

Plataforma web de consultoría y centro de entrenamiento de alto rendimiento diseñada bajo la estética **Tech-Chic Dark Mode** (#0B0F19, Cyan Neón #06B6D4 y Teal #14B8A6), optimizada para **CRO (Conversion Rate Optimization)** y captación de miembros.

---

## ⚡ Características Principales

- **Sistema de Consultoría 1-on-1:** Protocolo de transformación en 4 fases clínicas (Diagnóstico 360°, Prescripción Biomecánica, Nutrición & Biohacking, Auditoría Quincenal) con modalidades Presencial y Online/Remota.
- **Hero Section de Alto Impacto:** Telemetría cardíaca y biométrica en tiempo real (Zonas BPM, gasto calórico, efecto EPOC +36h).
- **Grid Interactivo de Disciplinas (5 Programas):** Calistenia Gravitacional, Cross Performance & Power, Hypertrophy & Biomechanics Lab, HIIT & Metabolic Pulse, e Isometric Tension & Neural Lab.
- **Laboratorio de Ejercicios Isométricos:** Simulador interactivo de dinamometría digital y reclutamiento neural (Overcoming & Yielding Isometrics).
- **Calculadora Interactiva de Metas:** Auto-segmentación según objetivo, días de entreno y nivel actual.
- **Horarios en Vivo:** Grilla semanal de clases con indicador de escasez de cupos restantes.
- **Prueba Social Verificada:** Testimonios reales con métricas auditadas por escáner InBody 770.
- **Captación de Leads de Alta Conversión:** Formulario multipasos con validación en React, generación de Pase Digital (`#AGY-XXXXXX`) y redirección a WhatsApp Concierge.
- **Mobile First CRO:** Barra inferior persistente para dispositivos móviles (*Mobile Sticky Bar*) y modal de retención de visitantes (*Exit-Intent*).

## 🛠️ Stack Tecnológico

- **React 19**
- **Vite 6**
- **Tailwind CSS 3** (Glow effects, paleta dark mode personalizada)
- **Lucide React** (Iconografía moderna)

## 🚀 Instalación y Puesta en Marcha

```bash
# 1. Clonar el repositorio
git clone https://github.com/mscandy3312/GymsMetraton.git

# 2. Entrar a la carpeta
cd GymsMetraton

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```
